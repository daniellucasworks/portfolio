So fügst du sie ein

  1. Gmail: Zahnrad → Alle Einstellungen aufrufen → Signatur → Neu erstellen → in das Feld klicken, Strg+V → unten Änderungen speichern.
  2. Outlook (Web): Einstellungen → Konto → Signaturen → Strg+V → Speichern.
  3. Outlook (Desktop): Datei → Optionen → E-Mail → Signaturen → Strg+V.
  4. Schick dir danach eine Test-Mail an dich selbst und schau sie am Handy und am Computer an.

Wenn dein Programm die eingefügte Signatur verändert, nimm HTML-Code kopieren und füge ihn dort ein, wo es HTML-Signaturen erlaubt.
